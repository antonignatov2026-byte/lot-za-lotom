# Лот за лотом

Бесплатная игра-аукцион для 2 или 3 игроков на одном экране. 20 тем, 320 предметов, 20 игровых рублей на игрока, 12 случайных неповторяющихся лотов за партию.

## Играть

Откройте сайт, выберите тему, количество игроков (2 или 3) и введите разные имена. Торгуйтесь вслух, затем введите окончательную цену и нажмите на победителя торгов. Пропуск лота бесплатный. Отмена хода возвращает деньги и выставляет тот же предмет снова. При исчерпании бюджетов всех игроков или 12 лотов показываются итоги; промежуточные итоги можно смотреть в любой момент.

В итогах — места для реалистичных изображений каждого игрока, список покупок и очки. Кнопка «Подготовить две картинки» или «Подготовить три картинки» собирает точный текст запроса: его нужно самостоятельно отправить помощнику в чат. Он может сгенерировать отдельные сцены; сохранённые картинки можно добавить кнопкой под каждым игроком и открыть крупно. **Автоматического вызова генератора на сайте нет.** Исходная SVG-схема осталась в раскрываемом списке покупок; она не является реалистичной сценой. Очки: сумма трёх характеристик всех покупок плюс 2 за каждый разный тип предметов. Характеристики видны до покупки. Цена не влияет на очки; неистраченные деньги бонуса не дают. При равенстве — ничья.

Режим выбирается перед новой партией, а не посреди текущей. Старые сохранения `version: 1` для двоих открываются без миграции. Третий игрок имеет собственный баланс, цвет, покупки, отмену хода, очки и изображение; экспорт включает ровно выбранное число игроков. Все режимы используют 12 лотов.

## Данные и ограничения

- Без регистрации, реальных денег, аналитики, внешних API и серверной базы.
- Загруженные изображения преобразуются на устройстве в JPEG до 1600 пикселей по длинной стороне для двоих и до 1280 для троих (с ограничением объёма для браузерного хранилища) и сохраняются вместе с партией. При изменении покупок изображения сбрасываются, чтобы не сравнивать старые наборы. При нехватке места браузер показывает предупреждение.
- Текст запроса ничего сам не отправляет: передача помощнику происходит только когда пользователь копирует и отправляет сообщение. Цены, очки и изображения в запрос не включаются.
- Имена и партия хранятся только в `localStorage` текущего браузера. Не публикуются в репозитории и не передаются игрой на сервер.
- Игра на двух отдельных устройствах не синхронизируется. Предполагается общий экран.
- Пять исходных тем содержат по 16 вручную оценённых предметов. У 15 дополнительных тем также по 16 предметов; их фиксированные характеристики задаются профилями типов и видны игрокам заранее.
- SVG-файлы можно сохранить кнопкой в итогах. Эмодзи могут выглядеть по-разному на разных устройствах.

## Локальный запуск

Статический сайт без сборки:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`.

## Проверки

```sh
npm ci
npx playwright install --with-deps chromium
npm test
npm run test:photos
npm run test:players
```

Сервер должен работать на порту 8765. Для другого адреса задайте `TEST_URL`. Скриншоты и SVG теста пишутся в `/tmp/lot-dvor-results` или `TEST_OUTPUT`.

Проверяются 20 тем / 320 уникальных лотов, полный цикл 12 ходов, балансы, недопустимые цены, покупка на весь бюджет, пропуски, отмена, восстановление после перезагрузки, итоги и очки, сохранение SVG, подтверждение новой игры, экранирование имён, повреждённое сохранение, ширины 320/360/390/768/1440. Отдельный сценарий фото проверяет точность двух списков, резервное копирование текста без доступа к буферу обмена, скачивание запроса, импорт изображений, просмотр, удаление, сохранение, отклонение повреждённых файлов, сброс при отмене покупки и совместимость старых сохранений.

Сценарий `test:players` проверяет выбор 2/3 игроков, сохранение введённых имён при переключении, повторяющиеся имена, третий баланс и покупателя, завершение только после исчерпания ВСЕХ бюджетов, возврат денег третьему, три результата/изображения/набора в запросе, восстановление, 12 ходов, обратное переключение и старое сохранение на двоих.

## Файлы

- `data.js`: темы, предметы и фиксированные характеристики.
- `app.js`: логика, сохранение, интерфейс, генерация коллекций.
- `style.css`: адаптивное оформление и локальный шрифт.
- `assets/nunito.ttf`: Nunito, SIL Open Font License (`assets/OFL.txt`).

Для обновлений используется тот же репозиторий `lot-za-lotom`, ветка `main`, GitHub Pages из корня. Не добавлять в публичный репозиторий реальные имена пользователей, фотографии, сохранения партий или секреты.
